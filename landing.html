Quick Start

Run the zero-dependency portable proof kernel locally in Python.

$ python3 hdar_portable.py demo --out /tmp/hdar_demo

# 2. Run Node.js 20/20 Cryptographic Verifier C
$ node verifier.js /tmp/hdar_demo
